# Configuration

In `adaptive-geo-ctrl-pybullet`, simulation configurations are defined as structured dictionaries generated by `agc.sim.default_scenario` and validated by `agc.sim.validate_scenario`.

## Creating a Scenario

```python
from agc.sim.default_scenario import default_scenario
from agc.sim.validation import validate_scenario

# Generate a default configuration dictionary
scenario = default_scenario(
    replay_id="lemniscate_01_auto",
    mode="bregman",       # "nominal", "euclidean", or "bregman"
    coriolis="lc",        # "lc" (Levi-Civita) or "rb" (coadjoint)
    duration=30.0,
    gain_source="optimized",  # "optimized" or "manual"
    gui=False,
)

# Validate consistency, timing ratios, and SPD properties
validate_scenario(scenario)
```

## Scenario Dictionary Structure

| Key | Type | Description |
| --- | --- | --- |
| `mode` | `str` | `"nominal"`, `"euclidean"`, or `"bregman"` |
| `coriolis` | `str` | `"lc"` or `"rb"` |
| `duration` | `float` | Flight simulation duration in seconds (e.g. `30.0`) |
| `dtPlant` | `float` | Physics simulation timestep (`0.002` s = 500 Hz) |
| `dtControl` | `float` | Control wrench update timestep (`0.02` s = 50 Hz) |
| `dtAdaptation` | `float` | Parameter adaptation update timestep (`0.01` s = 100 Hz) |
| `releaseTime` | `float` | Payload drop time (`10.0` s) |
| `plantBare` | `dict` | Bare vehicle inertial properties (`mass`, `com`, `inertia`) |
| `payload` | `dict` | Payload parameters (`mass`, `com`, `inertia`) |
| `plantLoaded` | `dict` | Compound vehicle + payload parameters |
| `controller` | `dict` | Controller gains (`KR`, `Kxi`, `Lambda`, `ks`, `kd`, `gammaE`, `gammaB`) |
| `sampler` | `ReplayTrajectory` | Continuous $C^1$ trajectory interpolator |
