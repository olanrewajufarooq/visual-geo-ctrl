# Monte Carlo physical-consistency verification

Generated by `python run/run_paper_sim.py physical-consistency-monte-carlo`.
The paired simulation figures are stored here; their report, summary, trial
data, initialization record, and implemented-parameter records use the
`physical_consistency_monte_carlo_` prefix under `results/papers/metadata/`
and `results/papers/tables/`. Rerunning the command updates these artifacts.

Plots use exact full-intensity RGB primaries, have no title, put legends above
the axes, and constrain the paired history to 0--30 s.
